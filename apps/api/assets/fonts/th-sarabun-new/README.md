Created by Suppakit CHALERMLARP.

Primary release: https://www.f0nt.com/release/th-sarabun-new/ (SIPA release, updated 15 November 2019).
Original archive: https://www.f0nt.com/download/sipafonts/THSarabunNew.zip
Government download listing linking to that archive: https://www.dgr.go.th/bgr3/th/download/635
Retrieved and verified: 2026-10-08.

The release page identifies GPL 2.0 + Font exception. Every included font's
name-table record 13 states GPL version 2 or later and the font embedding
exception. LICENSE-FONT.txt preserves that complete metadata text; COPYING.txt
contains GPL version 2 from https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt.
Redistribute these unmodified fonts with their notices and license. Embedding
unaltered font portions does not, by itself, put generated documents under GPL.
All four OS/2 fsType embedding flags are 0 (installable embedding).
