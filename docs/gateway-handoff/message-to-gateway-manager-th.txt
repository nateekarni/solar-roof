เรียนผู้จัดการ Gateway

ขอส่งร่างข้อมูลเชื่อมต่อระบบ Solar สำหรับตรวจสอบรูปแบบก่อนเริ่มทดลอง 1 Gateway ครับ

เว็บที่กำหนดไว้: solar.nateekarn.dev
MQTT ที่กำหนดไว้: mqtt-solar.nateekarn.dev

ขณะนี้ยังอยู่ระหว่างเตรียมระบบ ทั้งสองชื่อยังไม่ใช่การยืนยันว่าเปิดใช้งานแล้ว ทีมระบบจะแจ้ง port, บัญชีเชื่อมต่อ, topic และรหัสอุปกรณ์จริงหลังตั้งค่าและตรวจสอบเสร็จ

รบกวนตรวจเอกสาร gateway-connection-draft-th.md โดยเฉพาะตัวอย่าง JSON, หน่วยข้อมูล และวิธีรอข้อความยืนยันก่อนลบข้อมูลที่พักไว้ พร้อมแจ้งรุ่นอุปกรณ์ ตัวอย่างข้อมูลจริง ความสามารถ MQTT/TLS และการเก็บ/ส่งข้อมูลย้อนหลัง ตามตารางท้ายเอกสาร

หลังตกลงรูปแบบแล้ว เราจะนัดทดสอบส่งข้อมูลชุดแรก ตรวจการบันทึกและแสดงผล แล้วเริ่ม Pilot เพื่อดูปัญหาและปรับปรุงร่วมกันครับ
