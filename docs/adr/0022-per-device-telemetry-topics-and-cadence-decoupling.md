# Per-Device Telemetry Topics and Cadence Decoupling

ย้ายการกำหนดรูปแบบ Topic และรอบรับข้อมูล (Cadence) จากระดับเกตเวย์ลงสู่ระดับอุปกรณ์แต่ละตัว (มิเตอร์หลักและอุปกรณ์เพิ่มเติม) โดยระบบสร้างค่าอัตโนมัติตาม Site ID, Gateway ID และ Device ID พร้อมอนุญาตให้แก้ไขได้ เพื่อรองรับอุปกรณ์หลากหลายความถี่ (เช่น มิเตอร์ทุก 5 วินาที, SmartLogger ทุก 15 วินาที) และใช้ตรวจเทียบความถูกต้องของข้อมูล (Reconciliation) เมื่อข้อมูลส่งมาตรงกัน
