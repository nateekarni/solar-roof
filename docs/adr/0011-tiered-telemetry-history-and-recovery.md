# เก็บข้อมูลมิเตอร์ล่าสุดสำหรับค้นเร็ว และแยกประวัติระยะยาว

วันที่1ตุลาคม2569 ผู้ใช้ยืนยันเป้าประเมิน100โรงเรียน/1,000มิเตอร์ส่งทุกนาที/50ผู้ใช้พร้อมกัน และเลือกเก็บข้อมูลดิบล่าสุด90วันสำหรับค้นรายละเอียด เก็บข้อมูลดิบเก่ากว่าแยกสำหรับเรียกคืนภายใน1ชั่วโมง และใช้ข้อมูลสรุปสำหรับกราฟย้อนหลัง โดยหลักฐานคำนวณบิลต้องคงตรวจสอบได้ แนวทางนี้แทนการต้องค้นrawครบ2ปีจากฐานหลักทันที เพื่อจำกัดภาระqueryและพื้นที่ใช้งานประจำ โดยยอมให้รายละเอียดเก่ารอเตรียมข้อมูล

การเก็บarchiveไม่ใช่backup: ผู้ใช้กำหนดเป้ากู้ระบบภายใน4ชั่วโมง จุดกู้ฐานย้อนหลังไม่เกิน15นาที และGatewayส่งข้อมูลที่ขาดซ้ำได้ ต้องออกแบบและทดสอบแต่ละส่วนจริงก่อนรับรอง ไม่มีการเปิดretentionลบข้อมูลจากADRนี้ ต้องตรวจarchiveครบและกู้ได้ รวมทั้งคงboundaryreadings/mappingversions/issuedsnapshotsที่จำเป็นต่อการเงินก่อนนำrawออกจากฐานหลัก

อายุเก็บarchive/ความละเอียดและอายุข้อมูลสรุป ขนาดคำขอเรียกคืน และกลไกstorage/jobยังต้องกำหนดในแผนimplementation แนวทางนี้ยังไม่ใช่การยืนยันว่ามีserviceดังกล่าวทำงานอยู่แล้ว
