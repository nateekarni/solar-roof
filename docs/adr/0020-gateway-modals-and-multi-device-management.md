# 20. Gateway Dedicated Modals and Multi-Device Field Management

## Status
Accepted

## Context
1. หน้ารายการเกตเวย์ (`/gateways`) เดิมไม่มีการตอบสนองเมื่อผู้ใช้คลิกแถวในตาราง (`DataTable` ขาด `onRowClick`) และแบบฟอร์มการเพิ่ม/แก้ไขเกตเวย์ถูกแสดงเป็นการ์ดลอยท้ายหน้าจอ ทำให้เสียพื้นที่และบดบังภาพรวมรายการ
2. การเพิ่มเกตเวย์จำเป็นต้องกำหนดค่าอุปกรณ์ทั้งมิเตอร์หลัก (Billing Meter) และอุปกรณ์เสริม เช่น SmartLogger พร้อมทั้งจัดการ Field และหน่วยการแปลงข้อมูลได้ทันที โดยต้องรองรับการสลับมุมมองระหว่างตาราง (Table View) และ JSON (JSON View) สำหรับผู้เชี่ยวชาญ
3. อุปกรณ์แต่ละประเภทส่งข้อมูลด้วยรอบความถี่ (Interval / Cadence) ที่ไม่เท่ากัน (เช่น มิเตอร์ส่งทุก 10–60 วินาที, SmartLogger ส่งทุก 300 วินาที) โดย Interval เป็นค่าที่เกตเวย์เป็นผู้กำหนดส่งมา ระบบจึงต้องปรับขนาดหน้าต่างตรวจเทียบ (Comparison Window) ให้อิงตามอุปกรณ์ที่รอบช้าที่สุดโดยอัตโนมัติ

## Decision
1. **เพิ่ม Gateway Detail Modal (`gateway-detail-modal.tsx`)**: เปิดอัตโนมัติเมื่อคลิกแถวในตารางหรือเลือก "ดูรายละเอียด" รองรับการแสดงผลเต็มจอบนมือถือ (Mobile Full-Screen) และ Dialog บนเดสก์ท็อปตามแบบแผน ADR-0009
2. **แยกโมดอลเพิ่มและแก้ไขเกตเวย์ (`gateway-form-dialog.tsx` และ `gateway-edit-dialog.tsx`)**:
   - `GatewayFormDialog`: รองรับการลงทะเบียนเกตเวย์ใหม่ ผูกกับไซต์งาน กำหนดค่ามิเตอร์หลัก และเพิ่มอุปกรณ์เพิ่มเติม (SmartLogger)
   - `GatewayEditDialog`: หน้าต่างแท็บครบวงจรสำหรับจัดการเกตเวย์ อุปกรณ์ ฟิลด์ข้อมูล รอบรับข้อมูล คู่ตรวจเทียบ และการเผยแพร่คอนฟิก
3. **รองรับการสลับมุมมอง Table / JSON ในตัวจัดการฟิลด์**: เพิ่มตัวเลือกสลับมุมมองระหว่าง Table และ JSON Textarea ใน `DeviceProfileEditor` เพื่อความยืดหยุ่นในการตรวจสอบและแก้ไขฟิลด์
4. **มาตรฐานระยะห่าง Label กับ Input**: ปรับใช้ `<Field>` และ `<FieldLabel>` ร่วมกับระยะห่าง `gap-2` (8px) และ Input `h-10` สม่ำเสมอทั่วทุกฟอร์ม
5. **การตรวจเทียบข้อมูลข้าม Cadence**: ใช้ค่า `slowestCadence * 2` คำนวณขนาดหน้าต่างตรวจเทียบขั้นต่ำให้อัตโนมัติ เพื่อรองรับมิเตอร์และ SmartLogger ที่ส่งข้อมูลความถี่ต่างกัน

## Consequences
- ประสบการณ์การใช้งานจัดการเกตเวย์เป็นระเบียบ สอดคล้องกับหน้าอื่นๆ ในระบบ
- สามารถตรวจสอบและจัดการฟิลด์ของมิเตอร์และ SmartLogger ได้สะดวกทั้งแบบ Visual Table และ Raw JSON
- ป้องกันการแจ้งเตือนผิดพลาดจากการตรวจเทียบข้อมูลที่รอบการส่งไม่เท่ากัน
