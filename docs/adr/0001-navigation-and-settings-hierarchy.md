# 1. Navigation Hierarchy and Settings Consolidation

## Status
Accepted

## Context
เมนูบนแถบนำทางด้านข้าง (Side Navigation) เดิมมีจำนวนเมนูมากเกินไปและซ้ำซ้อนกับการทำงานในจุดอื่น เช่น เมนูรายงานซ้ำซ้อนกับหน้าภาพรวม และเมนูการแจ้งเตือนซ้ำซ้อนกับ Notification Popover บนแถบด้านบน นอกจากนี้ เมนูผู้ใช้งานและประวัติการทำงานควรอยู่ภายใต้การบริหารจัดการระบบเดียวกันกับการตั้งค่าระบบ

## Decision
1. ยุบรวมและจัดโครงสร้างเมนูหลักให้เหลือ 5 กลุ่มที่มีความหมายตรงไปตรงมา:
   - `ภาพรวม` (`/`)
   - `โรงเรียน` (`/schools`)
   - `ไซต์งาน` (`/sites`)
   - `สัญญาและเอกสาร` (`/contracts`, `/billing`, `/receipts`)
   - `ตั้งค่าระบบ` (`/settings/users`, `/settings/audit`, `/settings/meter-presets`, `/settings`)
2. ปรับ URL ของผู้ใช้งานและประวัติการทำงานให้สอดคล้องกับโครงสร้างลำดับชั้น ได้แก่ `/settings/users` และ `/settings/audit` พร้อมกำหนด Redirect จากเส้นทางเดิม
3. ตัดการใส่วงเล็บภาษาอังกฤษในข้อความเมนูภาษาไทยเพื่อแยกพจนานุกรม TH/EN ออกจากกันอย่างเป็นระเบียบ

## Consequences
- เมนูมีความกระชับ เรียนรู้และใช้งานได้ง่ายขึ้น ลดความสับสนของแอดมิน
- ลำดับชั้นของ URL (`/settings/...`) สะท้อนขอบเขตความปลอดภัย (Security Boundary) และโครงสร้างเมนูจริงอย่างตรงไปตรงมา
- ผู้ใช้ที่เข้าผ่าน URL เก่า (`/users`, `/audit`) จะยังคงใช้งานได้ผ่าน Redirection
