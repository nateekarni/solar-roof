# 8. System Page Full-Width Expansion and Power Flow Vector Diagram Spacing

## Status
Accepted

## Context
ในการใช้งานหน้าผังระบบ (`/system`) บนหน้าจอเดสก์ท็อปขนาดใหญ่ (1080p, 1440p, 4K):
1. หน้าระบบถูกจำกัดความกว้างไว้ที่ `max-w-7xl` (1280px) ทำให้มีช่องว่างสีขาวขนาดใหญ่ด้านซ้ายและขวา ไม่สอดคล้องกับหน้าแดชบอร์ดหลักที่ใช้ประโยชน์จากพื้นที่เต็มหน้าจอ (`w-full min-w-0 max-w-full`)
2. แผนผังจำลองการไหลของพลังงาน (Power Flow SVG Diagram) ภายในแท็บแรกถูกจำกัด `max-w-[420px]` และมี viewBox แค่ `0 0 340 370` ส่งผลให้โหนดการไหลฝั่งซ้าย ("ใช้จากโซลาร์") และฝั่งขวา ("ส่งออกสู่โครงข่าย") ชิดติดกับกล่อง "โรงเรียน" ตรงกลางเพียง 42px ทำให้ตัวเลข kW, เปอร์เซ็นต์ และข้อความกำกับดูบีบอัด แน่นชิด และอ่านค่ายาก
3. สัดส่วน Desktop 12 คอลัมน์เดิมแบ่งเป็น 7 : 5 ซึ่งทำให้พื้นที่ฝั่งผังไดอะแกรมยังแคบเกินไป ในขณะที่การ์ดสรุปข้อมูลฝั่งขวาถูกยืดให้กว้างเกินความจำเป็น

## Decision
1. **ขยายโครงสร้างหน้าเว็บเป็น Full-Width**:
   - ปรับคอนเทนเนอร์ใน [`apps/web/app/(app)/system/page.tsx`](file:///e:/solar-roof/apps/web/app/(app)/system/page.tsx) จาก `max-w-7xl mx-auto` เป็น `w-full max-w-full min-w-0 overflow-x-hidden` พร้อม Padding ขอบหน้าจอมาตรฐาน (`p-3 sm:p-4 md:p-6`) เพื่อให้กลมกลืนกับหน้าแรกและใช้พื้นที่จอแสดงผลได้อย่างเต็มประสิทธิภาพ

2. **ปรับอัตราส่วนคอลัมน์บน Desktop เป็น 8 : 4**:
   - ใน [`apps/web/features/dashboard/power-flow-card.tsx`](file:///e:/solar-roof/apps/web/features/dashboard/power-flow-card.tsx) เปลี่ยนจาก `lg:col-span-7` / `lg:col-span-5` เป็น:
     - **คอลัมน์ซ้าย (`lg:col-span-8 xl:col-span-8`)**: สำหรับผังไดอะแกรมหลัก (Power Flow / Schematic) เพื่อเปิดพื้นที่ให้ไดอะแกรมสามารถขยายขนาดได้อย่างเต็มที่
     - **คอลัมน์ขวา (`lg:col-span-4 xl:col-span-4`)**: สำหรับการ์ดข้อมูลสรุปวันนี้ 4 รายการ, รายได้สะสม, ลด CO₂, และสถานะความสมบูรณ์ ซึ่งมีขนาดพอเหมาะ กระชับ และสบายตา

3. **คำนวณพิกัดและขยายขนาด Power Flow SVG Diagram**:
   - ขยาย `viewBox` จาก `0 0 340 370` เป็น `0 0 580 350` (สัดส่วน ~16:10 แนวนอนธรรมชาติ)
   - ปรับ `className` ขยายขนาดสูงสุดจากเดิม 420px เป็น `max-w-[580px] lg:max-w-[660px] xl:max-w-[720px] mx-auto`
   - จุดศูนย์กลาง Center X ขยายเป็น `290`
   - โหนดซ้าย ("ใช้จากโซลาร์") อยู่ที่ x = 105 พร้อมการ์ดกรอบขนาด 140x76px
   - โหนดขวา ("ส่งออกสู่โครงข่าย") อยู่ที่ x = 475 พร้อมการ์ดกรอบขนาด 140x76px
   - กล่องโรงเรียนตรงกลางขยายเป็น 144x96px (x = 218 ถึง 362)
   - ระยะ Clearance แนวนอนระหว่างการ์ดโหนดซ้าย-ขวากับกล่องโรงเรียนเพิ่มขึ้นเป็นมากกว่า 43px และระยะ Center-to-Center เพิ่มเป็น 185px (จากเดิม 90px)
   - โหนดดึงจากโครงข่ายด้านล่าง (Import from Grid) ขยายเป็น 136x68px (x = 222 ถึง 358)
   - เส้น Flow ลูกศร และเส้น Bus Loop เชื่อมต่อกว้างขึ้นรับกับพิกัดใหม่อย่างลงตัว

4. **คงการแสดงผลแบบ Responsive ลงสู่อุปกรณ์พกพา**:
   - อุปกรณ์ Mobile (< 768px) และ Tablet (< 1024px) จะยุบเป็น 1 คอลัมน์แนวตั้งอัตโนมัติ โดย SVG Vector จะสเกลลดขนาดลงตามความกว้างหน้าจออย่างสมบูรณ์แบบ ไม่ล้นและไม่สูญเสียความคมชัด

## Consequences
- ผู้ใช้มองเห็นแผนผังการไหลของพลังงานอย่างโปร่งสบายตา ตัวเลขอ่านง่ายชัดเจน ไม่ซ้อนทับหรือเบียดชิดกันอีกต่อไป
- หน้าจอผังระบบมีความโอ่โถง สอดคล้องกับภาพรวมของ Solar Platform
- รักษาความเข้ากันได้กับธีม Light/Dark และระบบ i18n สองภาษาครบถ้วน
